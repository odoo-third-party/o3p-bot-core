O3P Bot Core

A small Odoo 19 addon that stores bot chats, groups, spaces, channels, and messages from Google Chat, Telegram, and WhatsApp in one normalized model layer.

Google Chat Telegram WhatsApp Chats Messages Raw payload retention

Models

botchat stores provider, chat ID, display name, group/direct type, provider resource names, profile fields, member state, activity timestamps, and raw API metadata.

botmsg stores provider message IDs, delivery state, sender/recipient data, text and HTML bodies, media, reactions, contacts, locations, polls, cards, buttons, interactive payloads, and webhook status data.

Provider coverage

Google Chat

Spaces, rooms, DMs, threads, cards, buttons, resource names, and event timestamps.

Telegram

Private chats, groups, supergroups, channels, usernames, commands, entities, media, polls, and replies.

WhatsApp

Business phone IDs, contacts, interactive messages, media IDs, status webhooks, reactions, delivery, and read receipts.

Menu

After installation, open Bot Core to manage chats and messages. Standard Odoo users can read and create records; system users can delete records when required.
